# ADR-009: Full-path additions: Antibody 3 and the unfinished melody

- **Decision:** after the Lite path and the evaluation were complete, add (1) **Antibody 3**
  "The tool you need depends on the thing that broke" (AWS S3 2017 + Cloudflare 2019), with two
  new relationships `DEPENDS_ON` and `FALLBACK_FOR` between systems, and (2) **the unfinished melody**
  (plan B12/D16) as a pure WAV renderer on the Echo page.
- **Context:** G0–G5 passed with days to spare; the user asked for the planned "aww" upgrades.
- **Guard rails:** the evaluation stays pinned to its three *declared* lessons, so the published
  numbers can't change; Antibody 3 passes every lesson check (7/7 quotes verbatim, two marked as
  remediation/practice inferences); the melody renders only the match result, never autoplays,
  and is paired with the alignment picture.
- **Demo:** a new plan, *Shrink the parcel photo archive*, is one step from Antibody 3 (3/4); the
  billing plan has the same dependency but a recorded fallback, so it stays quiet (2/4).
- **Not done:** Antibody 4, Resurrection, and a re-run evaluation including Antibody 3 (that would need
  a new declaration first).
- **Date:** 2026-10-15.
