# ADR-006: Lite path confirmed at G1 (plan D25, T10)

- **Decision:** stay on the **Lite** path.
- **Context:** G1 passed on day 1, well ahead of time, which the plan's rule says makes
  Full possible. But only prep day 1 was completed, and every remaining day involves
  new tools (Streamlit, LLM, evaluation).
- **Alternatives:** Full (adds Antibody 3, the melody, in-app LLM proposals).
- **Reason:** spend the time margin on correctness, the evaluation and the explanation,
  which judges can verify, rather than on extras.
- **Trade-off:** no melody. Re-check at G3: if all G3 tests are green early, add Antibody 3.
- **Date:** 2026-10-15.
