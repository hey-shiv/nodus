# ADR-002: Team and scope

- **Decision:** solo build, **Lite path** (plan D25).
- **Context:** one builder, four days, only day 1 of six prep days done (illness).
- **Alternatives:** Full path (adds the melody and more antibodies).
- **Reason:** Lite keeps the core loop (lessons → match → completion step → witness →
  outcome) and leaves time to learn the stack properly.
- **Trade-off:** fewer "wow" extras. Re-checked at G1 and G3: Full only if ahead.
- **Date:** 2026-10-15.
