# AI use disclosure

Graph Hacks allows AI coding assistants if their use is disclosed. This is that disclosure.

## Tools
- **Claude Code** (Anthropic, Claude Opus): explains concepts, drafts code and
  tests for approved function lists, reviews my changes, drafts diary entries.
- **Codex** (OpenAI): independent skeptical review of harder modules.
- **An LLM inside the product** (provider decided at D13, free tier): proposes lesson
  conditions for human approval and drafts wording. It never decides a match or a severity.

## How I review
- The concept, brief, decisions and test intentions are mine (see `docs/diary/`).
- Code is written in small, tested steps. I don't keep code I can't explain.
- Every step is logged with its reasoning in `docs/diary/LOG.md`, with exercises I
  answer to check my own understanding.
