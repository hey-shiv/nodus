# AI use disclosure

Graph Hacks allows AI coding assistants if their use is disclosed. This is that disclosure.

## While building
- **Claude Code** (Anthropic, Claude Opus) explained concepts, drafted code and tests for
  functions I approved, reviewed my changes, checked primary sources, and drafted the build
  diary entries, which I read and correct. The full step-by-step record (what, why, problems,
  fixes, questions and answers) is in [`docs/diary/LOG.md`](docs/diary/LOG.md). The
  self-test exercises I work through are in [`docs/diary/EXERCISES.md`](docs/diary/EXERCISES.md).
- **Codex** (OpenAI) is used for independent review of the core modules (compiler, matcher).
- The concept, the decisions (ADRs), the scope (Lite path) and the evaluation protocol
  are mine, recorded before or while building.

## Inside the product
- **What the AI may do:** draft a lesson from a post-mortem (`nodus/proposals.py`), using
  Gemini (free tier, optional key) or a local Gemma 4 model via Ollama.
- **What it may not do:** write the queries that run (a deterministic compiler does, from
  hand-written templates), decide a match or its severity (published rules do), approve or
  activate a lesson (only a person can, via `approve()`), or write the messages users see
  (templates filled from match results).
- **Every draft is checked automatically:** shape (pydantic), only whitelisted graph names,
  and every quoted sentence found word for word in the post-mortem. Failing drafts are retried
  twice, then quarantined.
- **The three lessons used in the demo and the evaluation were hand-authored**, then passed
  the same checks. They were not generated by the in-product LLM.
- Only synthetic or public text is ever sent to a model.
