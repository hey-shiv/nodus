# Evaluation declaration (written and committed BEFORE any evaluation data was generated)

Plan T30 / protocol E3. Everything below is fixed now. Results go in `eval/RESULTS.md`.
All data is **synthetic**.

## Questions
1. **Hits:** does structural matching find the right lesson for plans that share a lesson's
   structure but not its vocabulary?
2. **Restraint:** does it stay quiet for plans that share a lesson's vocabulary but not its structure?
3. **Foresight:** for a plan missing exactly one condition, does it report k = n − 1 and name that condition?

## Lessons
The three approved lessons in `data/lessons/` (antibody-1, antibody-2, internal-quiet-push),
unchanged. NODUS settings are fixed and were chosen before this declaration: an echo is
raised when k ≥ n − 1 (`nodus/severity.py`). Nothing in NODUS is tuned on evaluation data.

## Data: families (generated by `eval/generate.py`, seeded, in a separate graph per split)
Each plan gets its own system and alert channel, inside a shared synthetic company where
a staged procedure is followed by background plans. Plan text = title + one-sentence summary.
| Family | Construction | Expected (NODUS) |
|---|---|---|
| F1 same structure, different words | For a target lesson, all conditions realised (half the plans) or all but the completion step (the other half); text from fresh vocabulary unrelated to any lesson | target lesson raised (k ≥ n − 1) |
| F2 different structure, similar words | Text built from the target lesson's own keywords; structure safe (follows the procedure, automated + human gates, watched pager, partial rollout) with exactly one random risky attribute (routine, or rollout to all, or a single automated gate) | no lesson raised |
| F3 partial structure | For a target lesson, all conditions realised except one, chosen from the conditions that are neither company-level nor role-binders; fresh vocabulary | target lesson at k = n − 1 with exactly that condition missing |
| F4 unrelated | Fresh vocabulary, safe structure | no lesson raised |
| F5 adversarial | (a) a trivial change with the full risky shape; (b) a risky shape with the risk class not recorded; (c) the completion step replaced by a partial rollout while staying off the procedure | reported descriptively; no pass/fail claimed |

## Split
**dev** = seed 101, **test** = seed 202. Baseline thresholds are chosen on dev only. Test is run **once**.

## Metrics (always reported as "x of y")
- **F1 hit rate:** F1 plans where the target lesson is raised / F1 plans.
- **F2 false-alarm rate:** F2 plans where any lesson is raised / F2 plans.
- **F3 foresight accuracy:** F3 plans with k = n − 1 for the target lesson and the missing condition named correctly / F3 plans.
- **F4 false-alarm rate:** as F2.
- The same hit and false-alarm metrics for each baseline.

## Baselines (see plan D14), seeing the same plans and lessons
- **B2 keywords (will run):** TF-IDF cosine similarity between the plan text and each lesson's
  text (its name, summary, safe pattern, condition texts and all cited quotes from
  `data/lessons/`). Lowercase word tokens, a fixed English stopword list, IDF fitted on the
  three lesson texts plus the dev plans. A lesson is "raised" when similarity ≥ t. t is chosen on
  dev to maximise (F1 hits − F2 false alarms), ties to the higher t, then fixed for test.
- **B1 embeddings (conditional):** `all-MiniLM-L6-v2` cosine similarity, same protocol. Run
  only if `sentence-transformers` is installed (a large download on a slow connection). If not
  run, RESULTS.md says so.

## Integrity
Counts, not percentages alone; no significance claims; failures reported, including where
NODUS loses; no claims beyond these synthetic families. The demo world is not evidence;
only the test split is.

## Known threats to validity (repeated in the README)
- The families are built from the same condition definitions NODUS matches. This tests
  whether the graph queries implement the lessons and whether structure beats wording;
  it does **not** test whether role typing can be extracted from real documents (roles are given).
- Small n; synthetic text; the baselines are simple (no embedding + LLM re-ranking).
